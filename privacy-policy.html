プライバシーポリシー

トンマナビジュアライザー Chrome 拡張機能

1. 基本方針

トンマナビジュアライザー（以下「本拡張機能」）は、ユーザーのプライバシーを最大限に尊重します。本拡張機能は、個人情報の収集、保存、送信を一切行いません。

2. データの取り扱い

本拡張機能は、ユーザーが閲覧中のWebページのスタイル情報（CSS）を解析する機能を提供します。この処理に関して以下の方針を遵守します。

  • すべての解析処理はユーザーのブラウザ内（ローカル）でのみ実行されます
  • 解析結果を含むいかなるデータも外部サーバーに送信されません
  • ユーザーの閲覧履歴、個人情報、アカウント情報等を収集しません
  • Cookie やローカルストレージを使用しません

3. 権限について

本拡張機能は以下の Chrome 権限を使用します。これらはすべて、ページのスタイル解析機能の実現に必要なものです。

  • activeTab: ユーザーが操作中のタブのスタイル情報にアクセスするため
  • tabs: タブの切り替えを検知し、解析対象を追跡するため
  • scripting: ページ内でスタイル解析スクリプトを実行するため
  • sidePanel: 解析結果をサイドパネルに表示するため
  • host_permissions: 任意のWebページでスタイル解析を実行可能にするため

4. 第三者への提供

本拡張機能はデータを収集しないため、第三者へのデータ提供は一切ありません。

5. お問い合わせ

本プライバシーポリシーに関するご質問は、Chrome Web Store の拡張機能ページからお問い合わせください。

6. 変更について

本プライバシーポリシーは、必要に応じて更新される場合があります。重要な変更がある場合は、拡張機能のアップデートを通じてお知らせします。

Privacy Policy

Tonmana Visualizer — Chrome Extension

1. Overview

Tonmana Visualizer ("the Extension") is committed to protecting your privacy. The Extension does not collect, store, or transmit any personal information.

2. Data Handling

The Extension analyzes CSS style information of web pages you are currently viewing. Regarding this process:

  • All analysis is performed entirely within your browser (locally)
  • No data, including analysis results, is transmitted to any external server
  • We do not collect browsing history, personal information, or account credentials
  • No cookies or local storage are used

3. Permissions

The Extension uses the following Chrome permissions, all of which are necessary for its style analysis functionality:

  • activeTab: To access style information of the tab you are actively using
  • tabs: To detect tab switching and track analysis targets
  • scripting: To execute style analysis scripts within pages
  • sidePanel: To display analysis results in a side panel
  • host_permissions: To enable style analysis on any web page

4. Third-Party Sharing

Since the Extension does not collect any data, there is no data sharing with third parties.

5. Contact

For questions regarding this privacy policy, please contact us through the Extension's Chrome Web Store page.

6. Changes

This privacy policy may be updated as needed. Significant changes will be communicated through extension updates.
