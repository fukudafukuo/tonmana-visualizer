## 日本語

### 名前（45文字以内）
トンマナビジュアライザー

### 概要（132文字以内）
Webページの色・フォント・余白・装飾を自動解析。トーン＆マナーをサイドパネルで一覧表示。デザインの分析・参考・引き継ぎに。

### 説明（詳細）

Webページのトーン＆マナーを、ワンクリックで自動解析するChrome拡張機能です。

■ できること

・カラーパレット抽出 — 背景色・文字色・ボーダー色をカテゴリ別に整理。色コードをワンクリックでコピー
・フォント解析 — 使用フォント、サイズ、ウェイトを一覧表示。Google Fonts / Adobe Fonts / システムフォントを自動判別
・スペーシング分析 — margin / padding の使用パターンを可視化
・グラデーション検出 — linear / radial / conic グラデーションをプレビュー付きで表示
・装飾解析 — border-radius、box-shadow のパターンを収集
・コンテンツ幅 — width / max-width の設定パターンを検出
・WCAGコントラストチェック — 背景色と文字色の組み合わせをアクセシビリティ基準で評価
・トーン自動分類 — ミニマル / ポップ / コーポレート / ダーク等、サイトの印象を自動判定
・2サイト比較 — 異なるサイトのスタイルを並べて比較

■ こんな方におすすめ

・Webデザイナー：参考サイトのスタイルを効率的に分析したい
・ディレクター：デザインの意図やトーンを言語化したい
・コーダー：既存サイトのCSS設計を素早く把握したい
・デザイン学習中の方：プロのサイトがどんなスタイルで構成されているか知りたい

■ プライバシー

すべての解析処理はブラウザ内で完結します。データの外部送信は一切ありません。

## English

### Name
Tonmana Visualizer — Web Style Analyzer

### Summary (132 chars)
Auto-analyze any webpage's colors, fonts, spacing & decorations. Visualize tone & manner in a side panel. Perfect for design analysis.

### Description

A Chrome extension that automatically analyzes the tone and manner of any web page with a single click.

■ Features

- Color Palette Extraction — Background, text, and border colors categorized and ready to copy
- Font Analysis — Detect fonts, sizes, weights with source identification (Google Fonts / Adobe Fonts / System)
- Spacing Analysis — Visualize margin and padding usage patterns
- Gradient Detection — Preview linear, radial, and conic gradients
- Decoration Analysis — Collect border-radius and box-shadow patterns
- Content Width — Detect width and max-width patterns
- WCAG Contrast Checker — Evaluate text/background color combinations against accessibility standards
- Automatic Tone Classification — Categorize sites as Minimal, Pop, Corporate, Dark, and more
- Side-by-Side Comparison — Compare styles across two different websites

■ Who is this for?

- Web Designers: Efficiently analyze reference site styles
- Directors & PMs: Articulate design intent and tone
- Developers: Quickly understand existing CSS architecture
- Design Students: Learn how professional sites are styled

■ Privacy

All analysis runs entirely in your browser. No data is ever sent externally.
